ひとり仕事のAI実践はじめに

ひとり仕事のAI実践　全15回

ひとりで仕事をしている人が、自分の仕事の一部をAIに任せるための15回です。1回30分以内で、1回につき1つのことをやります。15回が終わると、現場の走り書きを置いて「見積を作って」と一言送るだけで見積書ができるところまで行きます（第14回）。PCが要るのは第3部だけで、プログラミングはしません。

詰まったら、その画面を送ってください。返事を返します。送り先は、このページを教えてくれた人です。教えてもらったときと同じ連絡先（LINE・メールなど）に、画面のスクショを送ってください。

各回には、入口が2つあります。「用意した素材でやる」は、こちらで作った練習用の資料を使う道です。やりたいことが特に無くても、資料の通りに進めれば1回が終わります。「自分のでやる」は、資料を自分の仕事のものに入れかえる道です。どちらを選んでもかまいません。

第1部　無料でやる

  1. AIに自分の仕事をさせてみる
  2. 書く仕事を渡す
  3. 調べる仕事を渡す
  4. 長い文を読ませる
  5. 渡せる仕事を1つ選ぶ

第2部　連携して任せる

  1. AIに自分のカレンダーを見せる
  2. 話し言葉でカレンダーに書き込ませる
  3. メールの返信案を一緒に作る
  4. 見積と請求を作らせる
  5. 自分の仕事の言葉を覚えさせる
  6. 資料を1枚作らせる

第3部　手間を消す

  1. Claude Code を入れて、最初の1個を動かす
  2. フォルダのファイルをまとめて処理させる
  3. 自分の手間を1つ、完全に消す
  4. 次の1年で何を任せるか決める

練習用の資料（ダウンロード）

練習用の資料

「かぜみち内装」という、ひとりで壁紙や床の張り替えをしている内装業の資料です。屋号もお客様も取引先も作り話です。第1回から順に使い、読み進めるとこの事業の様子が分かってきます。

  • 入口：この資料の説明（sample-README.txt）
  • 出費のメモ 8月〜10月（sample-expenses.csv）（第1回）
  • お客様からの問い合わせ3通（sample-inquiries.txt）（第2回）
  • 取引先との業務委託契約書（sample-terms.txt）（第4回）
  • 見積のもとになる現場の走り書き（sample-invoice-notes.txt）（第9回）

押すと、スマホでは「ファイル」アプリ（iPhone）か「ダウンロード」（Android）に、PCでは「ダウンロード」フォルダに入ります。

第1部　無料でやる（第1〜5回）

AIに「何を」「どんな形で」してほしいかを書いて渡す。第1部でやるのはこれだけです。使うのは Claude（クロード）というAIで、ふつうのWebの画面で使います。ChatGPT や Gemini でも同じ文で動きますが、この講座の画面の説明はすべて Claude のものです。この講座が Claude で進めるのは、第3部で使う道具が同じ Claude のアカウントで動くからです。

この講座で「新しい会話」と書いたら、画面の左上（スマホは三本線の中）の「新しいチャット」を押します。

「上限に達しました」と出たら、表示された時刻まで待てば、同じ会話の続きから使えます。

手順1Claude を開いて、ログインする

ブラウザ（スマホならSafariかChrome、PCならいつものもの）で claude.ai を開きます。「Googleで続ける」を押して、いつものGoogleのアカウントを選びます。Googleを使っていなければ、メールアドレスを入れて届いたコードで登録します。

途中で名前や年齢を聞かれたら、そのまま入れます。文字を入れる欄（「Claudeに話しかける」などと書いてある欄）が出たら、ログインできています。このページは閉じずに置いておき、Claude の画面と行き来します。

ここで止まったら　電話番号の確認を求められたら、そのまま自分の番号を入れて、届いた番号を打ちます。先に進めないときは、その画面を送ってください。

手順2設定で「Claudeの改善」への協力をオフにする

画面の左下にある自分の名前（スマホは左上の三本線 → 名前）を押し、「設定」→「プライバシー」と進みます。「Claudeの改善」についてのスイッチがあるので、オフにします。

オンのままだと、渡した内容がAIを良くするための材料に使われることがあります。オフにしても、使える機能は変わりません。登録の途中で同じことを聞かれて、もうオフにしてあれば、この手順は見るだけで終わりです。

ここで止まったら　名前が少し違っていても、「改善」「学習」と書かれたスイッチがそれです。見つからなければ、設定の画面を送ってください。

手順3出費のメモを、Claude に渡す

Claude の画面に戻り、入力欄の左にある「＋」（クリップの形のときもあります）を押して、「ファイル」から sample-expenses.csv を選びます。入力欄の上にファイルの名前が出れば、渡せています。

Claude の「設定」→「コネクタ」（「連携」と出ることもあります）を開き、一覧に Google カレンダーがあるかを見ます。「接続」が押せれば、いまのプランのままで進めます。

「接続」が押せない・アップグレードを求められたときは、第2部の最初の「分かれ目」に戻って、払うかを決めます。

つなぐ

「接続」を押すと、Googleの画面に変わります。自分のアカウントを選び、Claude にカレンダーを見せてよいかを聞かれたら「許可」を押します。つなぐのは claude.ai の画面からです。スマホのアプリより、PCかスマホのブラウザのほうが迷いません。

ここで止まったら　「Access blocked」（アクセスがブロックされました）と出たら、会社のGoogleアカウントで、管理者がつなぐことを止めています。自分で作った個人のGoogleアカウントで試してください。Google Workspace を自分で契約しているなら、自分が管理者なので、管理画面で許可できます。

用意した素材でやる

個人のGoogleカレンダーに、練習用の予定を3つ入れてから試します。来週の月曜10時「かぜみち 見積 お客様1」、水曜13時「かぜみち 材料の受け取り」、金曜9時「かぜみち 床 お客様3」。自分の本当の予定を見せたくない人は、練習用の Google アカウントを別に作り、そこに3つ入れてつなぎます。

自分のでやる

いつも使っているカレンダーをそのままつなぎます。

選び方：仕事の予定がいちばん多く入っているカレンダー。

読ませて、見比べる

つないだら、まず読むだけを頼みます。送る文：

私のGoogleカレンダーを見て、今週と来週の予定を、日付と時刻の順に全部書き出してください。予定の名前もそのまま書いてください。

返ってきた一覧を、自分のカレンダーの画面と1件ずつ見比べます。日付・時刻・件数が全部合っていたら、つなぐのは成功です。「接続済み」と出ていても、読めていない予定があることがあります。見比べるのは、その確認も兼ねています。

合っていたら、続けてこれを送ります。つないだあとで変わるのは、この1問です。

来週、2時間続けて空いている時間を3つ教えてください。移動の時間も考えて、前後に30分ずつあけてください。

空いている時間が3つ返ってきたら、この回は終わりです。

ここで止まったら　予定が足りない・1件も出ないときは、つなぎ直すときにカレンダーを選ぶ画面が出ていないかを見て、全部に印を付けてください。それでも合わなければ、Claudeの返事と自分のカレンダーの画面を両方送ってください。

来週の火曜の朝9時から2時間、「かぜみち 壁紙 お客様1」という予定を私のGoogleカレンダーに入れてください。

自分の来週の予定を、ふだん人に話す言い方で1つ頼みます。

ここで止まったら　「カレンダーには書き込めません」と返ってきたら、いまのつなぎ方は読むだけです。その場合は「予定の名前・日付・開始と終わりの時刻を1行で書き出してください」と送り、出てきた1行を見ながら自分でカレンダーに入れます。

私の Gmail で、件名が「かぜみち 問い合わせ」のメールを全部読んで、それぞれ返信の下書きを作ってください。下書きは画面に文章で出してください。Gmail には保存せず、送信もしないでください。

自分のでやる

実際に返事をためているメールで試します。

受信したメールのうち、差出人が「（ここに差出人を書く）」のメールを読んで、返信の下書きを作ってください。下書きは画面に文章で出してください。Gmail には保存せず、送信もしないでください。

このメモから見積書を作ってください。項目・単価・数量・金額の表にして、小計・消費税・合計を出してください。

消費税込みで85,343円前後（1円の差は端数の扱い）になれば、計算は合っています。合わなければ、どの行がずれているかAIに聞き返します。

自分のでやる

次に出す見積の走り書きを、そのまま貼ります。

選び方：毎回同じ形で作っているもの。

計算は、必ず1行は自分の電卓でも確かめます。合っていたら、同じ画面で「この見積を、工事が終わったあとに出す請求書の形にしてください」と続けます。見積と請求は同じ数字から作るので、ここまでで1つの仕事です。自分の見積書の様式に入れたいときは、「表計算（Excel や Googleスプレッドシート）に貼れる形にしてください」と送り、出てきた表を貼ります。

自分の屋号・よく使う単価・断る条件・決まった書き出しを、5行以内で書きます。

用意した素材でやる

選び方：消えても困らない、コピーしたフォルダ。

手順1　いまのプランを確かめる

Claude Code は、有料のプランに入っているアカウントで使えます。claude.ai の「設定」で、自分のプランの名前を見ます。「Pro」か「Max」と出ていれば使えます。「Free」なら、第2部の最初の「分かれ目」に戻ります。

手順2　Claude のデスクトップアプリを入れる

Windows

claude.ai/download を開き、Windows 用をダウンロードして開き、画面の通りに進めます。

Mac

claude.ai/download を開き、Mac 用をダウンロードし、開いたアプリを「アプリケーション」フォルダに入れます。

アプリを開いたら、claude.ai と同じアカウントでログインします。

ここで止まったら　入れたのに「Code」が使えない・ログインし直せと出るときは、アプリが入っていないのではありません。入れられたことと、使えるアカウントがあることは別です。まず、ログインしているアカウントのプランが「Free」のままでないかを見ます。次に、アプリの左下に出ているアカウントの名前が、第6回で払ったものと同じかを見ます。

手順3　「Code」を開いて、フォルダを選ぶ

アプリの画面の左のメニュー（無ければ上の切りかえ）に 「Code」 があります。押すと、作業するフォルダを選ぶ画面になります。デスクトップの「かぜみち」フォルダを選びます。

はじめてそのフォルダを開くと、「このフォルダを信頼しますか」という確認（英語で Trust と出ることもあります）が出ます。自分で作ったフォルダなので、信頼する（Trust）を押します。Mac では「デスクトップのファイルへのアクセスを許可しますか」という小さな窓が別に出ることがあります。これも「許可」を押します。

手順4　ファイルを1つ作らせる

入力欄に、この文を貼って送ります。

このフォルダの sample-expenses.csv を読んで、日付と金額を整えた表を「出費_整理済み.csv」という名前で、このフォルダに保存してください。

途中で「このファイルを作ってよいか」「このコマンドを実行してよいか」などの確認が、英語で何回か出ることがあります。自分で作ったフォルダの中の作業なので、どれも許可（Allow・Yes）を押します。終わったら、PCで「かぜみち」フォルダを開きます。「出費_整理済み.csv」ができていれば、この回は終わりです。開いたときに文字が化けていても、ファイルがあれば成功です。第1回では表が画面に出るだけでしたが、今度はAIがPCの中にファイルを作りました。
