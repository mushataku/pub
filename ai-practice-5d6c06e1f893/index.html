ひとり仕事のAI実践　全15回

ひとりで仕事をしている人が、自分の仕事の一部をAIに任せるための15回です。1回30分以内で、1回につき1つのことをやります。15回が終わると、現場の走り書きを置いて「見積を作って」と一言送るだけで見積書ができるところまで行きます（第14回）。PCが要るのは第3部だけで、プログラミングはしません。

詰まったら、その画面を送ってください。返事を返します。送り先は、このページを教えてくれた人です。教えてもらったときと同じ連絡先（LINE・メールなど）に、画面のスクショを送ってください。

各回には、入口が2つあります。「用意した素材でやる」は、こちらで作った練習用の資料を使う道です。やりたいことが特に無くても、資料の通りに進めれば1回が終わります。「自分のでやる」は、資料を自分の仕事のものに入れかえる道です。どちらを選んでもかまいません。

第1部　無料でやる（第1〜5回）

AIに「何を」「どんな形で」してほしいかを書いて渡します。ふつうのWebの画面でやります。

  1. 第1回　AIに自分の仕事をさせてみる散らかった資料をAIに渡して、表に整えさせる目安 30分以内・スマホだけでできる
  2. 第2回　書く仕事を渡す問い合わせへの返信の下書きを、AIに作らせる目安 30分以内・スマホだけでできる
  3. 第3回　調べる仕事を渡す調べものの答えを、出どころを聞いて確かめる目安 30分以内・スマホだけでできる
  4. 第4回　長い文を読ませる長い文書から、自分に関係する所だけを抜き出させる目安 30分以内・スマホだけでできる
  5. 第5回　自分の1週間を書き出して、渡せる仕事を1つ選ぶ自分の仕事の中から、AIに渡す仕事を1つ選ぶ目安 30分以内・スマホだけでできる

第2部　連携して任せる（第6〜11回）

AIに自分のカレンダーとメールを見せて、そこから仕事を任せます。お金がかかるかどうかの分かれ目は、第6回の最初にあります。

  1. 第6回　AIに自分のカレンダーを見せるAIに自分のカレンダーをつなぎ、予定を正しく読めているか確かめる目安 30分以内・スマホだけでできる（有料のプランが要ることがある）
  2. 第7回　話し言葉でカレンダーに書き込ませる話し言葉で頼んで、予定を正しい時刻で入れさせる目安 30分以内・スマホだけでできる（有料のプランが要ることがある）
  3. 第8回　メールを読んで、返信案を一緒に作るメールの返信を下書きまで作らせて、送信は自分で押す目安 30分以内・スマホだけでできる（有料のプランが要ることがある）
  4. 第9回　見積と請求を作らせる走り書きのメモから、計算の合った見積書と請求書を作らせる目安 30分以内・スマホだけでできる
  5. 第10回　自分の仕事の言葉をAIに覚えさせる屋号・単価・言い回しを覚えさせ、毎回説明しなくて済むようにする目安 30分以内・スマホだけでできる
  6. 第11回　資料を1枚作らせるお客様に渡す説明の資料を1枚、AIに作らせる目安 30分以内・スマホだけでできる

第3部　手間を消す（第12〜15回）

AIに自分のPCの中のファイルを直接さわらせます。PC（Windows か Mac）でやります。

  1. 第12回　Claude Code を入れて、最初の1個を動かすClaude Code に、自分のPCの中のファイルを1つ作らせる目安 30分以内（入れるのに時間がかかったら、手順4は次の日でもかまいません）・PC（Windows か Mac）が要る
  2. 第13回　自分のフォルダのファイルをまとめて処理させるフォルダの中の複数のファイルを、一度にまとめて処理させる目安 30分以内・PC（Windows か Mac）が要る
  3. 第14回　自分の手間を1つ、完全に消す毎回やっている作業を一言で終わる形にして、その手間を消す目安 30分以内・PC（Windows か Mac）が要る
  4. 第15回　次の1年で何を任せるか決めるこれから1年でAIに任せる仕事の順番を決める目安 30分以内・PC（Windows か Mac）が要る

スマホしか持っていない人へ

  1. 第1〜11回は、スマホだけで進められます。いまから始められます（第6〜8回で、有料のプランが要ることがあります。第6回の分かれ目で確かめます）。
  2. PC（Windows か Mac）が要るのは、第3部の第12〜15回です。第3部は、PCに加えて有料のプラン（月3,000円くらい・ドル建てなので為替で変わります）も要ります（第6回の分かれ目）。第11回の終わりに、進むかを決める分かれ目があります。
  3. 新品はいりません。中古のPCが、ジモティー・中古のお店・フリマで、1〜2万円くらいから出ています。下の最低線を満たすものなら、とにかく安いもので大丈夫です。手に入れたら、第12回から一緒にやってみましょう。
  4. 選ぶときの最低線は3つです。Windows 10 か 11 が動く／メモリは 8GB あると安心（4GB でも動きますが重い）／保存容量は 128GB 以上。Mac も使えます。値段や出ている数は、時期と場所で変わります。
  5. 買う前に、見つけたPCの画面（売り場の写真や説明）を送ってください。一緒に選びます。送り先は、このページの上の「詰まったら」と同じです。

練習用の資料

「かぜみち内装」という、ひとりで壁紙や床の張り替えをしている内装業の資料です。屋号もお客様も取引先も作り話です。第1回から順に使い、読み進めるとこの事業の様子が分かってきます。

  • 入口：この資料の説明（sample-README.txt）
  • 出費のメモ 8月〜10月（sample-expenses.csv）（第1回）
  • お客様からの問い合わせ3通（sample-inquiries.txt）（第2回）
  • 取引先との業務委託契約書（sample-terms.txt）（第4回）
  • 見積のもとになる現場の走り書き（sample-invoice-notes.txt）（第9回）

押すと、スマホでは「ファイル」アプリ（iPhone）か「ダウンロード」（Android）に、PCでは「ダウンロード」フォルダに入ります。
