第12回 / 全15回第3部　手間を消すPC（Windows か Mac）が要る目次へ

この回は PC（Windows か Mac）が要ります。スマホしか持っていない人は、目次の「スマホしか持っていない人へ」を先に読んでください。

第3部　手間を消す（第12〜15回）

第3部では、AIに自分のPCの中のファイルを直接さわらせます。ファイルを1つずつ渡す手間がなくなります。使うのは Claude Code（クロード コード）で、Claude と同じアカウントで使います。ターミナル（黒い画面）は使いません。

第3部は PC（Windows か Mac）でやります。はじめる前に、PCのデスクトップに「かぜみち」という名前のフォルダを作り、練習用の資料5つ（sample-README.txt と4本）をダウンロードして、そのフォルダに移しておきます。

第12回：Claude Code を入れて、最初の1個を動かす

できるようになること：Claude Code に、自分のPCの中のファイルを1つ作らせる

かかる時間：30分以内（入れるのに時間がかかったら、手順4は次の日でもかまいません）

使う素材：sample-README.txt・sample-expenses.csv・sample-inquiries.txt・sample-terms.txt・sample-invoice-notes.txt（5つとも「かぜみち」フォルダに入れる）

「かぜみち内装」は、この講座の練習用の作り話の内装業です（練習用の資料）。

この回の目標は1つだけです。Claude Code に、自分のPCの中にファイルを1つ作らせる。それができたら終わりです。全部で4つの手順です。

用意した素材でやる

練習用の資料5つ（README と4本）を、デスクトップに作った「かぜみち」というフォルダに入れておきます。手順4はこのフォルダで進めます。

自分のでやる

自分の仕事のファイルが入ったフォルダを使います。ただし最初は、中身をコピーした別のフォルダで試してください。

選び方：消えても困らない、コピーしたフォルダ。

手順1　いまのプランを確かめる

Claude Code は、有料のプランに入っているアカウントで使えます。claude.ai の「設定」で、自分のプランの名前を見ます。「Pro」か「Max」と出ていれば使えます。「Free」なら、第2部の最初の「分かれ目」（第6回のページの最初）に戻ります。

手順2　Claude のデスクトップアプリを入れる

Windows

claude.ai/download を開き、Windows 用をダウンロードして開き、画面の通りに進めます。

Mac

claude.ai/download を開き、Mac 用をダウンロードし、開いたアプリを「アプリケーション」フォルダに入れます。

アプリを開いたら、claude.ai と同じアカウントでログインします。

ここで止まったら　入れたのに「Code」が使えない・ログインし直せと出るときは、アプリが入っていないのではありません。入れられたことと、使えるアカウントがあることは別です。まず、ログインしているアカウントのプランが「Free」のままでないかを見ます。次に、アプリの左下に出ているアカウントの名前が、第6回で払ったもの（手順1で確かめたアカウント）と同じかを見ます。

手順3　「Code」を開いて、フォルダを選ぶ

アプリの画面の左のメニュー（無ければ上の切りかえ）に 「Code」 があります。押すと、作業するフォルダを選ぶ画面になります。デスクトップの「かぜみち」フォルダを選びます。

はじめてそのフォルダを開くと、「このフォルダを信頼しますか」という確認（英語で Trust と出ることもあります）が出ます。自分で作ったフォルダなので、信頼する（Trust）を押します。Mac では「デスクトップのファイルへのアクセスを許可しますか」という小さな窓が別に出ることがあります。これも「許可」を押します。

手順4　ファイルを1つ作らせる

入力欄に、この文を貼って送ります。

このフォルダの sample-expenses.csv を読んで、日付と金額を整えた表を「出費_整理済み.csv」という名前で、このフォルダに保存してください。

途中で「このファイルを作ってよいか」「このコマンドを実行してよいか」などの確認が、英語で何回か出ることがあります。自分で作ったフォルダの中の作業なので、どれも許可（Allow・Yes）を押します。終わったら、PCで「かぜみち」フォルダを開きます。「出費_整理済み.csv」ができていれば、この回は終わりです。開いたときに文字が化けていても、ファイルがあれば成功です。第1回では表が画面に出るだけでしたが、今度はAIがPCの中にファイルを作りました。

付録：黒い画面（ターミナル）でも使いたい人へ

この講座では使いません。慣れてから試したい人だけ読んでください。

Mac（ターミナルを開いて）

curl -fsSL https://claude.ai/install.sh | bash

Windows（PowerShellを開いて）

irm https://claude.ai/install.ps1 | iex

入ったら claude と打って Enter を押し、出てきた画面でログインします。

知っておくこと：Windows で「Git が要る」と出たら、表示に従って Git for Windows を入れてから、もう一度打ちます。パスワードを打っても画面に何も表示されないのは正常です。起動して「401」と出たら、ログインしたアカウントのプランが Claude Code を使えるものになっていません。

詰まったら、その画面を送ってください。返事を返します。送り先は、このページを教えてくれた人です。教えてもらったときと同じ連絡先（LINE・メールなど）に、画面のスクショを送ってください。
