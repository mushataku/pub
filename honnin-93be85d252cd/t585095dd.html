Python 宿題：障害報告の一覧をPythonで作ってみる

高木さん、面談でお話しした宿題です。選考とは関係のない、私からのおまけです。

基本情報がなかなか頭に入らないので Python も考えている、VBA と似ているところから始めたい、とおっしゃっていました。それなら教科書より先に、解く問題を1つ用意しようと思いました。

題材は、高木さんが電話対応の横で VBA を作って自動化された、障害報告の一覧の毎日の更新です。あれと同じことを Python でやります（課題1では、おまけで件数の集計もします）。データは練習用に作るもので、本物の業務データは使いません。

コードは全部、コピーして貼るだけで動きます。まず動かしてみて、慣れてきたら1語ずつ書き換えてみてください。スマホでは眺めるだけにして、作業はパソコンでどうぞ。

時間の目安（全部やって2時間ほど）

準備だけで止まっても十分です。空いた時間に少しずつで構いません。

1. 準備：Python と VS Code を入れる

最初のひと山はここです。順番どおりに進めれば40分ほどで終わります。詰まりやすい所は先に書いておきます。

1-1. 先に「アプリ実行エイリアス」をオフにする

Windows には、python と打つと Microsoft Store が開いてしまう設定が最初から入っています。先に切っておくと、あとで詰まりません。

  1. Windows の「設定」を開き、上の検索欄に「エイリアス」と入れて「アプリ実行エイリアスの管理」を開く
  2. 一覧から「アプリ インストーラー」の python.exe と python3.exe を探す
  3. その2つだけスイッチを「オフ」にする（名前が「Python」で始まるものがあれば、それはオンのまま）

1-2. Python を入れる

  1. ブラウザで python.org/downloads を開く
  2. 黄色い大きなボタンは押さずに、そのすぐ下の「Or get the standalone installer for Python 3.x.x」のリンクを押す（インストーラーがダウンロードされます）
  3. ダウンロードしたファイル（python-3. で始まる名前）を開く
  4. 最初の画面の一番下にある「Add python.exe to PATH」に必ずチェックを入れてから、「Install Now」を押す（ここが一番大事です）
  5. 「Setup was successful」と出たら「Close」で閉じる

1-3. 入ったか確かめる

  1. Windows の検索で「PowerShell」と入れ、「Windows PowerShell」を開く（入れる前から開いていたら、いったん閉じて開き直す）
  2. 次の1行を打って Enter を押す
PowerShell に打つ
python --version

Python 3.15.2 のように数字が出れば成功です。数字は違っていて構いません。Microsoft Store が開いたら、1-1 のスイッチを確かめてください。

1-4. Excel を扱う部品を足す

Python で Excel を読み書きするには、部品が2つ要ります。同じ PowerShell で次の1行を打ちます。数十秒かかります。

PowerShell に打つ
python -m pip install pandas openpyxl

最後に Successfully installed と出れば完了です。途中に黄色い WARNING が出ても、最後にこの字があれば成功です。pandas（パンダス）は表の集計が得意な部品で、面談で名前が出たのはこれです。openpyxl は Excel ファイルを読み書きする部品です。

1-5. VS Code を入れる

VS Code は、Python のコードを書いて動かすための画面です。VBA でいう VBE（Alt + F11 で開く画面）にあたります。

  1. code.visualstudio.com を開き、「Download for Windows」から入れる（途中の選択はそのまま進めて構いません）
  2. VS Code を開く。右下に「表示言語を日本語に」の案内が出たら、そのボタンを押して再起動する。出なければ、左端の四角が4つ並んだアイコン（拡張機能）で Japanese と検索し、「Japanese Language Pack」を入れて再起動する
  3. 拡張機能の検索欄に Python と入れ、Microsoft の「Python」を入れる

1-6. 最初の1行を動かす

  1. デスクトップに python-practice という空のフォルダを作る。この先の作業はすべてこの中でやります
  2. VS Code の「ファイル」→「フォルダーを開く」で、そのフォルダを選ぶ（「作成者を信頼しますか」と聞かれたら「はい」）。左上に PYTHON-PRACTICE と出ていれば合っています
  3. 左の一覧の上にある「新しいファイル」のアイコンを押し、hello.py と名前を付ける（最後の .py が目印です）
  4. 次の1行を貼って、Ctrl + S で保存する
hello.py
print("こんにちは、Python")

右上の三角ボタン（Python ファイルの実行）を押すと、下の画面に こんにちは、Python と出ます。ここまでで準備は終わりです。

VBA との違いで大きいのは2つです。1つ目は、変数の宣言が要らないこと。2つ目は for や if の書き方で、Next や End If の代わりに、行頭の字下げ（空白4つ）で「ここまでが中身」を表します。字下げがずれるとエラーになるので、コピーしたコードの行頭の空白は消さないでください。

3. 課題1：種類別・日別に件数を数える

平日5日ぶんの問い合わせの受付記録から、種類ごと・日ごとの件数を数えて、Excel の別シートに書き出します。VBA なら COUNTIF かピボットでやるところです。

3-1. 練習用の受付記録を作る

python-practice フォルダに make_data.py を作り、次のコードを貼って保存し、右上の三角ボタンで動かします。受付日・種類・対応の30件が入った 障害受付.xlsx ができます。# で始まる行はメモなので、動きには関係しません。

make_data.py
# 使う道具を呼ぶ（pandas は表を扱う道具。慣習で pd と短く呼ぶ）
import random
from datetime import date, timedelta
import pandas as pd

# 乱数の出方を固定する（誰がやっても同じデータになる）
random.seed(1)

# 問い合わせの種類と、どう対応したか（VBAの配列にあたる）
kinds = ["システムのエラー", "リモート接続", "プリンター", "その他"]
actions = ["案内で解決", "フラグを変更", "開発へ連絡"]

# 30回くり返して、1件ずつ箱に足す（For i = 0 To 29 と同じ）
rows = []
for i in range(30):
    rows.append({
        "受付日": date(2026, 11, 2) + timedelta(days=random.randint(0, 4)),
        "種類": random.choice(kinds),
        "対応": random.choice(actions),
    })

# 箱を表（DataFrame）に変え、受付日の順に並べる
df = pd.DataFrame(rows)
df = df.sort_values("受付日", ignore_index=True)

# Excelに書き出す（index=False は行番号の列を付けない指定）
df.to_excel("障害受付.xlsx", index=False)

# 中身を画面に出す（Debug.Print のかわり）
print(df)

下の画面に30行の表が出て、フォルダに 障害受付.xlsx が増えます。Excel で開いて中を見てみてください（見たら閉じておきます）。

3-2. 件数を数えて、別シートに書き出す

次に count.py を作って動かします。

count.py
import pandas as pd

# Excelを開いて表として読む（Workbooks.Open のかわり）
df = pd.read_excel("障害受付.xlsx")
# 日付だけにする（読み込むと時刻 0:00 が付くため）
df["受付日"] = df["受付日"].dt.date

# 種類ごとに件数を数え、多い順に並べる（COUNTIF のかわり）
by_kind = df.groupby("種類").size().reset_index(name="件数")
by_kind = by_kind.sort_values("件数", ascending=False)

# 日付×種類の件数表（ピボットテーブルのかわり）
by_day = pd.crosstab(df["受付日"], df["種類"])

# 3つのシートに書き出す（with を抜けると保存される）
with pd.ExcelWriter("件数まとめ.xlsx") as writer:
    df.to_excel(writer, sheet_name="明細", index=False)
    by_kind.to_excel(writer, sheet_name="種類別", index=False)
    by_day.to_excel(writer, sheet_name="日別")

# 結果を画面に出す
print(by_kind.to_string(index=False))
print(by_day)

画面に種類別の件数（システムのエラーが12件で一番多い）と、日付×種類の表が出ます。フォルダにできた 件数まとめ.xlsx には「明細」「種類別」「日別」の3シートが入っています。

できたかの確かめ方

  • 「種類別」の件数を足すと30になる
  • 「明細」シートで COUNTIF を1つ打って、どれか1種類の件数が合っている

1語だけ変えてみる：groupby("種類") を groupby("対応") に変えて動かすと、対応ごとの件数になります。

4. 課題2：毎日のファイルを一覧にまとめる

毎日の受付がファイルで増えていき、それを障害報告の一覧に足していく作業です。高木さんが VBA で回していたあの更新を、Python で書くとこうなります。三角ボタン1回で、一覧ごと作り直します。

4-1. 3日ぶんの受付ファイルを作る

make_days.py を作って動かします。毎日 フォルダができ、11月9日・10日・11日の3ファイルが入ります。

make_days.py
import random
from datetime import date
from pathlib import Path
import pandas as pd

# 毎回同じデータになるように固定
random.seed(2)
kinds = ["システムのエラー", "リモート接続", "プリンター", "その他"]
actions = ["案内で解決", "フラグを変更", "開発へ連絡"]

# 「毎日」フォルダを作る（すでにあってもエラーにしない）
Path("毎日").mkdir(exist_ok=True)

# 9日・10日・11日の3回くり返す
for day in [9, 10, 11]:
    rows = []
    # その日の件数は3〜8件のどれか
    for i in range(random.randint(3, 8)):
        rows.append({
            "受付日": date(2026, 11, day),
            "種類": random.choice(kinds),
            "対応": random.choice(actions),
        })
    # その日のExcelに保存（例：毎日/受付_2026-11-09.xlsx）
    name = f"毎日/受付_2026-11-{day:02d}.xlsx"
    pd.DataFrame(rows).to_excel(name, index=False)
    print(name, "を作りました", len(rows), "件")

4-2. 全部を一覧にまとめる

update_list.py を作って動かします。VBA なら Dir でファイルを回して、一覧シートの最終行の下へ貼り付けていく処理です。

update_list.py
from pathlib import Path
import pandas as pd

# 「毎日」フォルダの 受付_〜.xlsx を全部集めて並べる（Dir のかわり）
files = sorted(Path("毎日").glob("受付_*.xlsx"))

# ファイルを1つずつ開いて読み、箱に入れる（For Each のかわり）
frames = []
for f in files:
    frames.append(pd.read_excel(f))

# 箱の中の表を上から順に1つへつなぎ、日付だけにする
ichiran = pd.concat(frames, ignore_index=True)
ichiran["受付日"] = ichiran["受付日"].dt.date

# 先頭に通し番号の列を足す
ichiran.insert(0, "No", range(1, len(ichiran) + 1))

# 種類別の件数（課題1と同じ）
by_kind = ichiran.groupby("種類").size().reset_index(name="件数")

# 「一覧」と「種類別」の2シートに書き出す
with pd.ExcelWriter("障害報告一覧.xlsx") as writer:
    ichiran.to_excel(writer, sheet_name="一覧", index=False)
    by_kind.to_excel(writer, sheet_name="種類別", index=False)

print(len(files), "日ぶんを一覧にしました:", len(ichiran), "件")

画面に 3 日ぶんを一覧にしました: 13 件 と出れば成功です。障害報告一覧.xlsx を開くと、通し番号つきの一覧と種類別の件数が入っています。

もう一歩：次の日のぶんを足す

開いている Excel を閉じてから、make_days.py の [9, 10, 11] を [9, 10, 11, 12] に変えて動かし、そのあと update_list.py をもう一度動かします。12日のファイルが増え、一覧は4日ぶん17件になります。新しい日が来ても、三角ボタンを押し直すだけで一覧が最新になります。
