gitとGitHubのちがいはじめに

高木さんへ　gitとGitHubのちがい

11月20日（金）　／　株式会社SeeD 武者野

「git」と「GitHub」は名前がそっくりですが、別のものです。このタブでは、2つがそれぞれ何で、どうつながっているのかを、困りごとから順に4段で説明します。実際に入れて使い始める手順は「GitHubを始めるまで」のタブにまとめました。

  1. 1困りごと：「最終版_v2」
  2. 2git＝PCで記録を取る道具
  3. 3GitHub＝記録を置く場所
  4. 42つの関係：push と pull
  5. 5ちがいを表で
  6. 6転職でどう役に立つか

1. 困りごと　ファイル名に「最終版_v2」が増えていく

段1／4

VBAのマクロや報告書を直すとき、壊すのが怖くて元のファイルをコピーしてから触った経験はないでしょうか。続けていくと、フォルダの中がこうなります。

この困りごとを解くのが、次の段の git です。

2. git＝自分のPCで、変更の記録を取る道具

段2／4

git（ギット）は、自分のパソコンに入れて使うソフトです。ファイルはコピーせず1つのまま、「ここまで動いた」という時点ごとに記録を残します。記録の1つ1つをコミットと呼び、それぞれに「何を変えたか」のひとことメモが付きます。

記録した時点へ、いつでも戻れる

ゲームのセーブポイントと同じです。書き換えて壊してしまっても、記録した時点へ戻せます。だから気軽に試せます。

記録はフォルダの中にしまわれる

gitで記録を取るフォルダをリポジトリと呼びます。見た目は普通のフォルダで、中に .git という隠しフォルダができ、記録はそこにたまります。

gitだけでも使える（ネットがなくても動く）

ここが大事な点です。gitはパソコンの中だけで完結します。インターネットにつながっていなくても、記録を取る・戻すはできます。gitを作ったのはLinuxの開発者で、無料で誰でも使えます。

3. GitHub＝gitの記録を置いて、見せ合うネット上の場所

段3／4

gitの記録はPCの中にあるので、そのままでは他の人に見せられませんし、PCが壊れれば一緒に消えます。そこで、記録を丸ごとネット上に預けておく場所が GitHub（ギットハブ）です。ソフトではなく、ブラウザで開くWebサービスです（会社としてはマイクロソフトの傘下にあります）。

GitHubと同じように記録を預けられるサービスは他にもあります（GitLab など）。gitはどのサービスとも組み合わせられます。求人票やIT企業でいちばんよく名前が出るのがGitHubです。

4. 2つの関係　ローカルとリモート、push と pull

段4／4

gitとGitHubを組み合わせると、同じリポジトリが2か所にできます。手元のPCにあるものをローカル、GitHubにあるものをリモート（離れた所）と呼びます。

そろえる操作は2つだけです。

push（プッシュ）ローカルの新しい記録を、リモート（GitHub）へ上げる。
pull（プル）リモートにある新しい記録を、ローカルへ取ってくる。

そろえる順番：先に取ってきて、それから上げる

GitHubの画面で直接ファイルを直した場合など、リモートの方が新しいときは、先に pull で取ってきてそろえてから push します。

ひと言だけ：ブランチ

慣れてくると出てくる言葉にブランチ（枝）があります。これもgitの機能です。最初のうちは本線の main 1本だけで十分なので、名前だけ覚えておけば大丈夫です。

5. ちがいを表で

ここまでを1枚の表にまとめます。

gitGitHub
何かソフト（道具）Webサービス（場所）
どこで動くか自分のPCの中ネット上（ブラウザで開く）
何をするか変更の記録を取る・前の記録へ戻す記録を預ける・人に見せる・共有する
相手が無くても使えるか使える（GitHubが無くても、ネットが無くても動く）gitで作った記録を置く場所なので、gitとセットで使う
入れ方PCにインストールするアカウントを作る（インストールは要らない）

6. 転職でどう役に立つか

IT職の面接では「Pythonを勉強しています」と言うより、「これが書いたコードです」とURLを1本見せる方がずっと伝わります。GitHubに置いたコードは、中身に加えていつ・どのくらいの頻度で・何を直してきたかの記録まで見えます。毎週少しずつ記録が積み上がっていれば、それ自体が「続けて勉強している」証拠になります。

面接で聞かれたら、「gitで手元の変更を記録して、GitHubに push して公開しています」と言えれば十分です。gitとGitHubを分けて言えること自体が、分かっている人の言い方になります。
