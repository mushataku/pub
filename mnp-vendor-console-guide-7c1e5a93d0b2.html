MNP 依頼コンソールの使い方

あなたがやることは3つだけです

  1. ①依頼を出す
  2. ②名義人さんに「リンク」を1回渡す
  3. ③こちらから聞かれたら答える

それ以外——本人確認の準備・期限が切れたときの出し直し・申込の続き——は、こちらが自動でやります。

はじめに：コンソールを開く

MNP 依頼コンソールを開く

こちらにお伝えいただいた Gmail（Google アカウント）でログインします（PC でもスマホでも使えます）。LINE の中で開いてログインできないときは、右上のメニューから「ブラウザで開く」（または「Safari で開く」）を選んでください。「登録されていません」と出たら別のアカウントで入っています。シークレット（プライベート）ウィンドウで開き直すと、アカウントを選び直せます。

①依頼を出す

  1. 1「新しい依頼」を押す
  2. 2名義人さんのお名前（漢字）・フリガナ・性別・郵便番号・連絡先の電話を入れる
  3. 3本人確認に使う書類を1つ選ぶ
  4. 4承諾の2つにチェック（名義人さんご本人に同意をもらってから）
  5. 5「この内容で依頼する」を押す

押すと受付番号（例 xx-1006a）が出ます。一覧には名義人さんのお名前が出ないので、受付番号とお名前を控えておいてください。

書類の写真は送りません。郵便番号や電話は全角・ハイフン付きでも大丈夫です。足りない所は赤く出ます。二度押ししても依頼は1件です。

②名義人さんに「リンク」を1回渡す

依頼のあと数分〜10分ほどで、「依頼の一覧」のカードに「名義人さんに渡すリンク」が出ます（30分たっても出なければ、受付番号を添えてご連絡ください）。

  1. 1下の「文面の見本」を先に送ってから、カードの受付番号が送る相手の番号か確かめ、「名義人さんのリンクをコピー」を押し、いつもの連絡手段（LINE・メールなど）で名義人さんへ送る。送るのは最初の1回だけです（名義人さんがなくしたら、同じリンクをもう一度送って大丈夫です）
  2. 2進み具合（見るだけ）。「本人確認URL送信済み」はこちらの準備ができたという意味で、名義人さんにはまだ届いていません。届けるのはあなたが送るリンクです
  3. ✕「いまの本人確認 URL」と、その下の「URL をコピー」は使いません（約90分で使えなくなります）。「本人確認の URL を送り直す」も、カードに「『送り直す』を押してください」と出ていないときは押さないでください（前の URL が使えなくなり、名義人さんの手続きがやり直しになることがあります）

同じリンクは、こちらから届くメール（件名「【MNP代行】本人確認のURL（受付番号）」）にも載っています。メールの中でも、名義人さんに送るのは「名義人さん用のページ」のリンクのほうです。

名義人さんへ送る文面の見本

本人確認のお願いです。下のリンクをスマホで開き、「本人確認を始める」を押して進めてください。
用意するもの：お知らせいただいた書類（運転免許証など）の実物（IC チップを読み取ります。写真やコピーは使えません）／運転免許証・マイナンバーカードならその暗証番号（4桁）／顔を写せる明るい場所。
途中で本人確認用のアプリ（LIQUID eKYC）を入れる案内が出ます。暗証番号はまちがえ続けると使えなくなるので、うろ覚えなら先に確かめてください。
リンクはこのあと送ります。

名義人さんのスマホには、こう出ます

このページにも一覧にも、名義人さんのお名前・住所は出ません。

③こちらから聞かれたら答える

入力の確認などで、こちら（このご案内をお送りした者）からご連絡することがあります。そのときだけ答えてください。予約番号もこちらからお知らせします。それ以外は待つだけです。

よくある問い

本人確認の URL の期限（約90分）が切れたら？
何もしなくて大丈夫です。カードには赤字で「新しい URL を自動で用意しています」と出ますが、こちらが用意している途中という意味です。名義人さんが同じリンクを開けば、数分で新しいボタンが出ます。赤字が「『送り直す』を押してください」のときだけ、下の「まれにあること」へ。
名義人さんが本人確認を済ませたら？
こちらで申込の続きを進めます。待つだけで大丈夫です。しばらくするとカードが「本人確認済み」に変わります。
困ったときは？
受付番号を添えて、こちらへご連絡ください。

まれにあること

カードに赤字で「『送り直す』を押してください」と出たときだけ、あなたの手番です。自動の出し直しが止まっている依頼で、名義人さんの画面には「新しいご案内は、担当者からお知らせします」と出ています（この「担当者」は、名義人さんから見たあなたのことです）。名義人さんからそう言われたら、カードを見てください。こちらで気づいたときもご連絡します。

  1. 「本人確認の URL を送り直す」を押し、確認で OK を押す（押したあとは「受け付けました」と出て、もう押せなくなります）
  2. しばらくして赤字が消え、カードに新しい URL が出たら、名義人さんに「前に送ったリンクを、もう一度開いてください」と伝える（新しい URL は送りません）
