MNP 依頼コンソールの使い方

依頼を出して、本人確認の URL を受け取るまでの流れです。1 枚で終わります。

  1. 受付
  2. 本人確認URL送信済み
  3. 本人確認済み
  4. 申込完了
  5. 予約番号発行済み

1. 開く

ご案内した URL を開き、ご案内を受けた Gmail の Google アカウントでログインします。

登録されていないアカウントでは「登録されていません」と出ます。別のアカウントで開いている場合は、アカウントを切り替えてください。

2. 依頼を出す（「新しい依頼」）

  • 名義人さんのお名前（漢字）・フリガナ・性別・郵便番号・連絡先の電話を入れる
  • 本人確認に使う書類を1つ選ぶ
  • 承諾の2つにチェック（名義人さん本人の同意と、本人確認は本人が行うこと）
  • 「この内容で依頼する」を押す

書類の写真は送りません（ここでは受け取りません）。全角の数字やハイフン付きの郵便番号でも大丈夫です。足りない項目は赤く表示されます。二度押ししても依頼は1件です。

3. 状態を見る（「依頼の一覧」）

依頼ごとに、いまどこまで進んだかが出ます。画面は 30 秒ごとに読み直します。

名義人さんのお名前は一覧には出ません。依頼の見分けは「受付番号」（例 xx-1006a）で行います。

4. 本人確認の URL を名義人さんへ渡す

  • URL が届くと一覧に出ます（依頼してから数分〜）。「URL をコピー」で名義人さんに送ってください
  • 有効期限は約90分です。期限は「M月D日（曜）H時M分まで」と表示されます
  • 本人確認（書類の撮影と顔の撮影）は名義人さん本人がスマホで行います

5. 期限が切れたら「送り直す」

期限が切れると URL は消えます。「本人確認の URL を送り直す」を押すと、新しい URL を用意します（押したあとは「受付済み」と出て、押せなくなります）。新しい URL が届くと一覧が変わります。

本人確認が済んだ依頼では、このボタンは出ません。

困ったときは、受付番号を添えてご連絡ください。
