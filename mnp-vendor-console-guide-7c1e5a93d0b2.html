MNP 依頼コンソールの使い方

あなたがやることは3つだけです

  1. ①依頼を出す
  2. ②名義人さんに「リンク」を1回渡す
  3. ③こちらから聞かれたら答える

それ以外——本人確認の準備・期限が切れたときの出し直し・申込の続き——は、こちらが自動でやります。

はじめに：コンソールを開く

MNP 依頼コンソールを開く

こちらにお伝えいただいた Gmail（Google アカウント）でログインします（PC でもスマホでも使えます）。LINE の中で開いてログインできないときは、右上のメニューから「ブラウザで開く」（または「Safari で開く」）を選んでください。「登録されていません」と出たら別のアカウントで入っています。シークレット（プライベート）ウィンドウで開き直すと、アカウントを選び直せます。

①依頼を出す

  1. 1「新しい依頼」を押す
  2. 2名義人さんのお名前（漢字）・フリガナ・性別・郵便番号・連絡先の電話・生年月日（西暦8桁。例 19900102）を入れる（「控え」欄はこちらの管理番号などを入れたいときだけ・任意）
  3. 3本人確認に使う書類を1つ選ぶ
  4. 4承諾の2つにチェック（名義人さんご本人に同意をもらってから）
  5. 5「この内容で依頼する」を押す

押すと受付番号（例 xx-1006a）が出ます。この番号を控えてください（一覧のカードにも「受付番号」として出ます）。一覧には名義人さんのお名前が出ないので、見分けは受付番号か、「控え」に入れた管理番号で。

名義人さんの端末の EID（数字32桁）は任意の欄です。分かっていれば先に入れておくと早く進みます（iPhone は 設定→一般→情報→EID／Android は 設定→デバイス情報→SIM のステータス など）。分からなければ空のままで大丈夫です（あとでカードから入れられます）。書類の写真は送りません。郵便番号・電話・生年月日は全角・ハイフン付きでも大丈夫です。足りない所は赤く出ます。二度押ししても依頼は1件です。

②名義人さんに「リンク」を1回渡す

依頼のあと数分〜10分ほどで、「依頼の一覧」のカードに「名義人さんに渡すリンク」が出ます（30分たっても出なければ、受付番号を添えてご連絡ください）。

  1. 1下の「文面の見本」を先に送ってから、カードの受付番号が送る相手の番号か確かめ、「名義人さんのリンクをコピー」を押し、いつもの連絡手段（LINE・メールなど）で名義人さんへ送る。送るのは最初の1回だけです（名義人さんがなくしたら、同じリンクをもう一度送って大丈夫です）
  2. 2「いま誰の番か」の1行（見るだけ）。「名義人さんの番です」と出たら、名義人さんが本人確認をする番です（あなたが送ったリンクを開いてもらいます）。「こちらで手続き中です」と出たら、あなたの作業はありません

同じリンクは、こちらから届くメール（件名「【MNP代行】本人確認のURL（受付番号）」）にも載っています。メールの中でも、名義人さんに送るのは「名義人さん用のページ」のリンク1本だけです。カードの下の「本人確認の URL を送り直す」は、こちらからお願いしたとき以外は押さないでください（前の URL が使えなくなります）。

名義人さんへ送る文面の見本

本人確認のお願いです。下のリンクをスマホで開き、「本人確認を始める」を押して進めてください。
用意するもの：お知らせいただいた書類（運転免許証など）の実物（IC チップを読み取ります。写真やコピーは使えません）／運転免許証・マイナンバーカードならその暗証番号／顔を写せる明るい場所。
途中で本人確認用のアプリ（LIQUID eKYC）を入れる案内が出ます。暗証番号はまちがえ続けると使えなくなるので、うろ覚えなら先に確かめてください。
リンクはこのあと送ります。

名義人さんのスマホには、こう出ます

一覧には名義人さんのお名前・住所は出ません。名義人さんのページは、名義人さんが生年月日を入れると、お名前と本人確認のボタンが出ます（生年月日が合わないうちは、どちらも出ません）。

③こちらから聞かれたら答える

EID を先に入れていないときは、申込が完了したあとに、カードに「名義人さんの端末の EID を入れてください」が出ます。名義人さんから EID を聞いて、入力欄に入れて「EID を送る」を押してください（ハイフンや空白があっても大丈夫です。打ち間違いはその場で赤く出ます）。入れたあとは「EID 受け取り済み（末尾4桁 …○○○○）」と出ます。こちらが LinksMate に出す前なら「EID を入れ直す」で直せます。出したあとに直すときは担当者へご連絡ください。

入力の確認などで、こちら（このご案内をお送りした者）からご連絡することがあります。そのときだけ答えてください。予約番号は、発行されるとカードに出ます（こちらからもお知らせします）。それ以外は待つだけです。

よくある問い

本人確認の URL の期限（約90分）が切れたら？
何もしなくて大丈夫です。カードに「期限が切れました。新しい URL を自動で用意しています」（夜間は「名義人さんがリンクを開くと新しくなります」）と出ますが、こちらが用意します。名義人さんが同じリンクを開けば、新しいボタンが出ます。
予約番号はどこに出ますか？
最後の手続きが済むと、カードが「予約番号発行済み」になり、予約番号と有効期限がカードに出ます。
EID はどこで見つけますか？
名義人さんの端末で確かめます。iPhone は 設定→一般→情報→EID／Android は 設定→デバイス情報→SIM のステータス など（機種で違います。出ないときは「EID」で設定内を検索してもらってください）。数字32桁です。打ち間違いは eSIM の再発行になり事務手数料がかかるため、入力時に先頭8桁と検査数字を確かめて、合わなければ赤く出します。
名義人さんが本人確認を済ませたら？
こちらで申込の続きを進めます。待つだけで大丈夫です。しばらくするとカードが「本人確認済み」に変わります。
困ったときは？
受付番号を添えて、こちらへご連絡ください。

まれにあること

カードに「担当者が手で新しい URL を出します。押す必要はありません」と出たときは、自動の出し直しが止まっていて、こちらが手で新しい URL を出します。あなたの作業はありません（押すボタンも出ません）。名義人さんの画面には「新しいご案内は、担当者からお知らせします」と出ます（この「担当者」は、名義人さんから見たあなたのことです）。名義人さんからそう言われたら、「少しお待ちください」とお伝えください。新しい URL が出たら、カードの「いま誰の番か」が変わります。
