会社資料コネクタ 設定の手順

これは何

紹介先企業の資料（勤務地・待遇・研修など）を、Claude のチャットから聞くだけで引けるようにする設定です。設定は最初の1回だけ・2手です。

全体の流れ（2手）

この2手のあとは、新しいチャットでもそのまま聞けます。

手1: コネクタを足して接続する

  1. claude.ai を開き、カスタマイズ → コネクタ → 自分のもの → ＋追加 → カスタムコネクタを追加
  2. 名前は「会社資料」、URL は拓也から送られたものをそのまま貼る（別の形に直さない）
  3. Connect を押し、Google のログインでGooner の業務アドレスを選ぶ（1タップ）
  4. 「このコネクタを使える人の一覧に入っていない」と出たら、拓也に連絡（アドレスの登録漏れ）

手2: 権限を「常に許可」にする

  1. 最初に質問したとき「承認が必要」と出る（初期値）
  2. 常に許可を選ぶ（3つのツールをまとめて切り替わる・1回だけ）

3つとも読むだけのツールです。資料は書き換わりません。

使い方

普通にチャットで聞きます。例:「入社時に契約社員から始まる紹介先は？」「HIT は既往歴があっても選考できる？」
答えに資料の名前（どの文書か）が出ます。出なかったら「どの文書に書いてある？」と聞き返してください。

困ったとき

  • 「到達できませんでした」→ URL の貼り間違い。送られた URL をそのまま貼り直す
  • 呼び出されない → チャット下の「＋」→ コネクタで「会社資料」が入っているか見る
  • 資料に無いこと → 「載っていない」と返るのが正しい動き。推測で答えさせない
