1. この宿題のゴール

高木さんがVBAで普段やっていた、次の流れをPythonで1本動かします。

Excelを開く → 集計する → 別シートや別ファイルに書き出す

VBAで6年以上これをやってこられた高木さんなら、考え方はもう頭に入っています。新しく覚えるのは書き方だけです。書き方の違いは次の「対応表」にまとめたので、「あのVBAはこれのことか」と読み替えながら進めてください。

完成すると、こんなことができるようになります。

  • 売上のExcelから、担当者ごとの合計を自動で出す
  • 月ごとに分かれたExcelを、1つのファイルにまとめる

2. 準備：PythonとVS Codeを入れる

最初の関門がここです。手順どおりに進めれば40分ほどで終わります。つまずきやすい所は先に書いておくので、順番を飛ばさずに進めてください。

2-1. 先に「アプリ実行エイリアス」を切る

Windowsには、Pythonと打つとMicrosoft Storeが開いてしまう設定が最初から入っています。これを先にオフにしておくと、あとで詰まりません。

  1. Windowsの「設定」を開き、「アプリ」→「詳細設定」→「アプリ実行エイリアス」を開く（Windows 10の場合は「アプリと機能」の中にあります）
  2. 一覧から python.exe と python3.exe を探す
  3. 両方のスイッチを「オフ」にする

2-2. Pythonを入れる

  1. ブラウザで python.org/downloads を開く
  2. 黄色い「Download Python 3.x.x」のボタンを押して、インストーラーをダウンロードする
  3. ダウンロードした python-3.x.x-amd64.exe を開く
  4. 最初の画面の一番下にある「Add python.exe to PATH」に必ずチェックを入れる。そのあとで「Install Now」を押す（ここが一番大事です）
  5. 終わりの画面で「Disable path length limit」と出たら、それも押してから閉じる

2-3. 入ったか確かめる

  1. Windowsの検索で「PowerShell」と入力し、「Windows PowerShell」を開く（入れる前から開いていた場合は、いったん閉じて開き直す）
  2. 次の1行を打って Enter を押す
PowerShellに打つ
python --version

Python 3.13.7 のように数字が出れば成功です。数字は違っていて構いません。Microsoft Storeが開いてしまったら、2-1に戻ってスイッチを確認してください。

2-4. VS Codeを入れる

VS Codeは、Pythonのプログラムを書くためのエディタです。VBAでいうVBE（Visual Basic Editor）にあたります。

  1. code.visualstudio.com を開き、「Download for Windows」からダウンロードして入れる（途中の選択はそのまま進めて大丈夫です）
  2. VS Codeを開く。左端の四角が4つ並んだアイコン（拡張機能）を押す
  3. 検索欄に Japanese と入れ、「Japanese Language Pack」の「Install」を押す。終わったら右下の「Restart」で再起動すると、メニューが日本語になる
  4. もう一度拡張機能の検索欄で Python と入れ、Microsoftが出している「Python」を「Install」する

2-5. Excelを扱う部品を足す

PythonでExcelを読み書きするには、追加の部品が2つ要ります。PowerShellで次の1行を打ちます。数十秒かかります。

PowerShellに打つ
pip install pandas openpyxl

Successfully installed と出れば完了です。pandas は表の集計が得意な部品、openpyxl はExcelファイルを読み書きする部品です。

2-6. 動作確認：最初の1行

  1. デスクトップなどに python-practice という空のフォルダを作る。以後の作業はすべてこの中でやります
  2. VS Codeで「ファイル」→「フォルダーを開く」から、そのフォルダを選ぶ
  3. 左の一覧で新しいファイルのアイコンを押し、hello.py という名前にする（最後の .py が目印です）
  4. 次の1行を書いて、Ctrl + S で保存する
hello.py
print("こんにちは、Python")

右上の三角ボタン（Run Python File）を押すと、下の画面に こんにちは、Python と出ます。ここまで来れば準備は完了です。

VBAとの大きな違いを2つだけ挙げておきます。1つ目は、Pythonは字下げ（行頭の空白）で「ここからここまでが中身」を決めることです。End If や Next の代わりに、字下げが区切りになります。2つ目は、表をまるごと1つの値として扱えることです。VBAでセルを1つずつ回していた処理が、1行で済むことがよくあります。

4. 課題1：担当者別に集計して書き出す

売上のExcelを開いて、担当者ごとの合計を出し、新しいExcelに書き出します。練習用のデータもPythonで作るので、手元にExcelを用意する必要はありません。

4-1. 練習用の売上データを作る

python-practice フォルダに make_data.py を作り、次のコードを貼って保存し、右上の三角ボタンで実行します。担当者・日付・商品・金額の20行が入った 売上データ.xlsx ができます。各行の右の # 以降はメモで、動きには関係しません。

make_data.py
import random                          # 乱数を使う道具を呼ぶ
from datetime import date, timedelta   # 日付を扱う道具を呼ぶ
import pandas as pd                    # 表を扱う道具。慣習で pd と短く呼ぶ

random.seed(1)                         # 乱数の出方を固定する（誰がやっても同じデータになる）
members = ["佐藤", "鈴木", "田中", "伊藤"]                                          # 担当者の一覧（VBAの配列にあたる）
prices = {"ノートPC": 98000, "モニター": 24000, "キーボード": 6000, "マウス": 3000}  # 商品名と単価（辞書）

rows = []                              # 1行ずつ入れる空の箱
for i in range(20):                    # 20回くり返す（For i = 0 To 19 と同じ）
    item = random.choice(list(prices)) # 商品を1つランダムに選ぶ
    rows.append({                      # 1行ぶんのデータを箱に追加する
        "担当者": random.choice(members),                  # 担当者をランダムに選ぶ
        "日付": date(2026, 10, 1) + timedelta(days=i),     # 10月1日から1日ずつ進める
        "商品": item,                                      # さっき選んだ商品
        "金額": prices[item] * random.randint(1, 3),       # 単価 × 1〜3個
    })

df = pd.DataFrame(rows)                # 箱を表（DataFrame）に変える
df.to_excel("売上データ.xlsx", index=False)   # Excelに書き出す（index=False は行番号の列を付けない指定）
print(df)                              # 中身を画面に出す（Debug.Print のかわり）

実行すると、下の画面に20行の表が出て、フォルダに 売上データ.xlsx が増えます。Excelで開いて中身を見てみてください。

4-2. 担当者別に集計して、別シートに書き出す

次に agg.py を作ります。VBAなら、Excelを開いて、ピボットかSUMIFで合計して、新しいシートに貼り付けるところです。

agg.py
import pandas as pd                                    # 表を扱う道具を呼ぶ

df = pd.read_excel("売上データ.xlsx")                   # Excelを開いて表として読み込む（Workbooks.Open のかわり）
total = df.groupby("担当者")["金額"].sum()              # 担当者ごとに金額を合計する（ピボットや SUMIF のかわり）
total = total.reset_index()                            # 結果を普通の表の形に戻す
total = total.sort_values("金額", ascending=False)     # 金額の大きい順に並べ替える

with pd.ExcelWriter("担当者別集計.xlsx") as writer:     # 書き出し先のExcelを開く（withの中で書き、抜けると保存される）
    df.to_excel(writer, sheet_name="明細", index=False)    # 元データを「明細」シートに書く
    total.to_excel(writer, sheet_name="集計", index=False)  # 集計結果を「集計」シートに書く

print(total)                                           # 結果を画面に出す

実行すると、担当者4人の合計が金額の大きい順に画面へ出ます。フォルダにできた 担当者別集計.xlsx を開くと、「明細」と「集計」の2シートが入っています。

同じ名前のExcelをExcelで開いたまま実行すると、PermissionError（書き込めません）と出ます。Excelを閉じてからもう一度実行してください。

できたかどうかの確認

  • 画面に4人ぶんの合計が出ている
  • 「集計」シートの数字が、「明細」シートから自分でSUMIFした値と合っている（1人ぶんだけ確かめれば十分です）

少し変えてみる（余裕があれば）：商品別の合計にするには、groupby("担当者") を groupby("商品") に変えるだけです。担当者×商品の2軸にしたいときは groupby(["担当者", "商品"]) と書きます。

5. 課題2：月別ファイルを1つにまとめる

月ごとに分かれたExcelを1つにまとめる作業は、VBAでよく作られる定番の処理です。これをPythonで置き換えます。

5-1. 月別ファイルを3つ作る

make_months.py を作って実行します。月別 フォルダができ、8月・9月・10月のExcelが入ります。

make_months.py
import random                          # 乱数の道具
from datetime import date, timedelta   # 日付の道具
from pathlib import Path               # フォルダやファイルを扱う道具
import pandas as pd                    # 表を扱う道具

random.seed(2)                         # 毎回同じデータになるように固定
members = ["佐藤", "鈴木", "田中", "伊藤"]                                          # 担当者の一覧
prices = {"ノートPC": 98000, "モニター": 24000, "キーボード": 6000, "マウス": 3000}  # 商品と単価
Path("月別").mkdir(exist_ok=True)      # 「月別」フォルダを作る（すでにあってもエラーにしない）

for month in [8, 9, 10]:               # 8月・9月・10月の3回くり返す
    rows = []                          # この月の行を入れる箱
    for i in range(8):                 # 1か月ぶん8行つくる
        item = random.choice(list(prices))                  # 商品を選ぶ
        rows.append({
            "担当者": random.choice(members),                # 担当者を選ぶ
            "日付": date(2026, month, 1) + timedelta(days=i * 3),  # 1日、4日、7日…と3日おき
            "商品": item,
            "金額": prices[item] * random.randint(1, 3),
        })
    pd.DataFrame(rows).to_excel(f"月別/売上_2026-{month:02d}.xlsx", index=False)  # 月ごとのExcelに保存

print("月別フォルダに3ファイルを作りました")

5-2. 全部を1つに結合する

merge.py を作って実行します。VBAでは Dir でファイルを回し、コピーして貼り付ける形になる処理です。

merge.py
from pathlib import Path                               # フォルダやファイルを扱う道具
import pandas as pd                                    # 表を扱う道具

files = sorted(Path("月別").glob("売上_*.xlsx"))        # 「月別」フォルダの売上_〜.xlsx を全部集めて並べる（Dir のかわり）
frames = []                                            # 読み込んだ表を入れる箱

for f in files:                                        # ファイルを1つずつ取り出す（For Each のかわり）
    d = pd.read_excel(f)                               # そのファイルを開いて読み込む
    d["元ファイル"] = f.name                            # どのファイル由来か分かる列を足す
    frames.append(d)                                   # 箱に入れる

all_df = pd.concat(frames, ignore_index=True)          # 箱の中の表を上から順に1つへつなぐ
all_df.to_excel("全月まとめ.xlsx", index=False)         # 1つのExcelに書き出す
print(len(files), "ファイルを結合しました:", len(all_df), "行")   # 件数を確認として出す

画面に 3 ファイルを結合しました: 24 行 と出れば成功です。全月まとめ.xlsx を開くと、24行と「元ファイル」の列が入っています。
