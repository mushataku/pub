待合室の「守り」は、それぞれ公平さをどれだけ動かすか

練習用の人口シミュレーション（実在サイトには触れていない）。主張に使うのは守り間の相対差だけで、絶対値は仮置きの人口設定による。 正規900人・転売30人・在庫300・抽選で400件入場。各点は30試行の平均、棒の線は SE。

読み取れたこと
  • 転売が身元を多く持てる世界（C=10）では、守りを1つだけ入れても正規の当選確率は全部offの0.004から 最大0.033までしか動かない。穴が7つあり、1つ塞いでも別の穴から入られるため。
  • C が大きいほど、守りの働きは身元の数（①）に集約される。①だけを入れた場合は C=200 でも当選確率 0.033 の低水準で一定。C が小さい世界（C=1）では⑦が最大の動き。
  • 積む順（図2）は ①身元上限→⑦注文1回・上限→②1身元1列→⑤入口の確認→④券を縛る。積んだ後に足しても数字が動かない守りは ③入口の費用・⑥注文の確認。
  • ⑤（入口の確認）と⑥（注文の確認）は、⑦を入れた後は互いの代わり＝どちらか1つで素通りと裏口が塞がる。積む順で後に来た方が加算 0 に見えるのは、先に入った方が同じ穴を塞いでいるため。
  • ③④の働きは、転売の予算と券の使い回し数の仮置きに依存する（攻め側は守りを見ず試すだけで、弾くのは待合室の判定）。設定を変えれば順位は変わる。

図1 守りを1つだけ入れたとき（C=10）

横軸＝入れた守り（全部offが基準）。縦軸＝上: 正規の当選確率（高いほど公平）／下: 上位5%占有率（低いほど公平）。 どの守りも単独では、占有率を1.0近くから下げきれない。穴は束で埋めないと数字に出ない。

図2 守りを貪欲に積む（C=10）

正規の当選確率が最も上がる守りを順に足した。横軸＝積んだ段階。段を重ねるごとに占有率が下がり、最後の2〜3段は動かない（他の守りがすでに同じ穴をふさいでいる）。

図3 転売が持てる身元数 C を振る

横軸＝C（穴1の強さ）。全部offでは C が増えると正規の当選確率は 0 に張りつく。全部onは ① が C を 2 に頭打ちにするため C≥2 で一定（C=1 は身元上限が空振りなので水準が少し高い）。 ⑦だけ・①だけでは、C の全域で全部onに届かない。

C を 1〜200 まで伸ばしても、束の守り（貪欲積みの到達点）の当選確率は C≥2 で一定値に飽和し、0 へは崩れない。 これは構成上の帰結: ①身元上限が転売の使える身元を C によらず一定数に頭打ちにするため、C を上げても攻め側に新しい取り分が増えない。 ①を外した構成（全部off・①以外の単独）は C が小さい側で悪化するが、C≳30 から先は横ばい: 転売1人の試行上限（attempt_cap=200・1身元あたり6列）で約33身元までしか使えず、C=50〜200 の値は C≈34 の複製に近い（動くのは②だけ）。「束でも勝てない領域」はこの人口設定の C≤200 には現れなかったが、束の飽和は①の cap=2 から必ずそうなる結論で、「C を上げたとき束が支える下限」を独立に測ったものではない（cap を C に連動させた構成が次の測定）。

定数は仮置き（SPEC「練習用待合室の攻守」）。穴と守りの対応は Queue-it の公式ドキュメントから整理したもので、実サイトでの再現検証はしていない。
