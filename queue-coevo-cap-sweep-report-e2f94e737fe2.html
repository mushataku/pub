守り①の身元上限（cap）を緩めると、束はどこで崩れるか

練習用の人口シミュレーション（実在サイトには触れていない）。正規900人・転売30人・在庫300。各点30試行の平均（± は SE）。cap と C 以外の定数は前巡のまま。

読み取れたこと
  • C が cap に届くまでは、cap の値によらず同じ曲線（C=1→2→5 で 0.305→0.275→0.205）に乗る＝cap が働かない間は①無しと同じ。崩れ始める C は cap で決まらず、C=5 で全 cap が同時に下がり始める（C=1 の値の80%を割る点・cap=2 だけは下がらない）。
  • cap が決めるのは頭打ちの高さ。束は cap=2 が 0.275・cap=5 が 0.205・cap=10 が 0.186・cap=30 が 0.186。C=200 でも 0 へは崩れない。cap=10・30 は①無しと同じ値＝束の中では③の予算（有料6回）が C=6 で頭打ちにしていて、cap を6以上に緩めても束は①無しの 0.186 より下がらない（図1で cap=10・30 の線は重なる）。
  • ③を外すと cap が緩いほど頭打ちが低い: cap=2 が 0.275、cap=5 が 0.205、cap=10 が 0.142、cap=30 が 0.066（①無しは C に比例して下がり続け 0.013）。
