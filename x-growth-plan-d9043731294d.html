武者野さん向け。2026-11-07 時点。詳細と出典は repo の docs/research/x-single-account-growth-2026-11.md が正本です。ここは判断に要る部分だけを、重みを付けて抜き出しました。

先に訂正します。この調査の読者像は、施工管理の経験者ではありません。未経験枠の「ユウタ」（24歳・飲食ホール3年目）です。施工管理の測定（5章）は、読者そのものでなく、受け皿側（求人・紹介する側）を測っています。

先に結論

  1. 武者野さんの決定（2026-11-07）：X は本命の一つ。理由は「投稿は資産化にならないけどアカウントは資産になる」。下の弱点は消えていません。
  2. 育て方の骨格は、テキスト＋図の「1本目で完結する投稿」を1日1〜3本、CA が体験つきで返信、リンクはプロフィールに置いて LINE へ、週次で中央値を測る、です。
  3. 基本は Grok ではありません。投稿は人か公式 API、下書きは Claude、Grok は X の検索役です。
  4. 評価の中身は噂でなくなりました。2026-08-13 以降、公開コードに重みの実数があります。大きいのは読者の返信、引用、共有、フォロー。いいねは軽く、ミュート、興味なし、通報は桁違いに重い。一次
  5. AI は下書きまで。投稿と返信は人が押します。AI 返信 bot は事前の書面承認が要ります。一次
  6. 受け皿側の施工管理界隈は、求人・紹介・派遣の定型投稿が最大級の層（27.5%、次点は26%）で、反応はほとんどありません。565件中87%が反応ゼロ。一次小標本 空きは「エージェント不信への正面回答」「数字つきの一次体験」「チェックリスト型」と読めます。推測
  7. ユウタ層の声は、X に少ない。無作為120件のうち、強い当事者は 8%（95%区間で 5〜15%）、強と緩いを合わせても 20% です。その反応はほぼ無し。読むだけの人は見えません。一次小標本

弱い所（先に言います）

  • 本丸の棄却理由「資産化しない、放置耐性がない」は、コードで裏づけられました。X は48時間で候補から消えるフロー媒体で、残るのはフォロワーと関係、LINE 登録です。判断軸の「止まらない運用」とは緊張があります。一方、棄却理由のうち、ルールとしての「リンク減点」と「新規アカウント係数」は、コードに見つかりませんでした（リンクの実効は割れています）。なお48時間は For You 候補の足切りで、検索やプロフィール経由の残り方は調べていません。
  • 読者のユウタ層は、X に居ても少ない側です（強い当事者 8%・強と緩いを合わせても 20%、反応ほぼ無し）。読むだけの人は未到達です。
  • 小規模・日本語・人材で応募が増えると証明された型は、1件も見つかりませんでした。第三者が検証できる90日記録は0件、人材×X×LINE の数字付き事例も0件です。未到達 だから計画は「測りながら進め、見直し条件を先に書く」形です。
  • 投稿を週1回の予約にまとめられるかは未確認です。純正の予約投稿の公式記載が見つかっていません。

一次 公式・公開コード・査読論文・生データを見せた当事者独立 利害のない第三者事業者 売る側のデータ未検証 自称・伝聞推測 ここでの推論未到達 調べたが届かなかった

1. 判断軸との緊張

事業の判断軸は、工数あたりの応募貢献、止まらない運用、自動化に寄せる、の3つです。X はこれらと緊張がある媒体です。一方、資産は投稿でなくアカウント（フォロワーと関係）に残ります。

判断軸X の性質
止まらない運用 > 一時的なバズ48時間で配信候補から消える。返信にも人の手が要る
武者野さん本人の手動投稿を前提にしない純正の予約が使えなければ、毎日の手投稿になる
自動化に寄せる（人はクリエイティブの承認だけ）AI は下書きまで。投稿と返信は人が押す（段階 A）
工数あたりの応募貢献小規模・日本語・人材での実績は未確認 未到達

本命の一つとして回す条件は、次の4点です。

  1. 張り付くのは武者野さんでなく CA。同じ整理を Threads でも採っています。
  2. 投稿は週1回のまとめ作業に圧縮する。純正の予約か同等の手段が使えることを、準備日の go 条件にします。
  3. 時間あたりの LINE 登録を、他媒体と比べ続ける。判断軸は比較量です。比較先の数字は、まだありません。
  4. 入口を X だけに頼らない。「アカウントは資産」は、読者が揃ってはじめて成り立ちます。入口を他にも持ち、判定はフォロワー数でなく、X 経由の LINE 登録で行います。

2. 何が評価されるか

2026-08-13 以降、xai-org/x-algorithm の公開コードに重みの実数が入りました。照合した版は HEAD 3b6919f です。重みは cron で同期されるため、使う前に原典で確かめ直してください。

2-1. 行動ごとの重み

式は「スコア = Σ(重み × その人がその行動をとる予測確率)」です。重みは生の件数に掛かりません。「通報1件でいいね468件が消える」は誤読だと、README とコードのコメントが明言しています。一次

確率と掛け算なので、重みが大きくても確率が小さければ寄与は小さくなります。実際の順位は外から分かりません。プロフィールクリックと動画の視聴の重みは 0 です。ブックマークに直接の重みはありませんが、閲覧者の履歴などには入っていて、間接の余地はあります。

2-2. 投稿の一生

  • 2時間以内の cold start は、フォロワー5万以下・表示200回未満で、既に候補に入っていて順位が上位97%以内の元投稿への抽選枠です。当たると1リクエスト1件まで、15位相当に引き上げられます。実験群の制御つきで、全員に適用される保証はありません。
  • 同じ著者は、1回の取得で2本目から ×0.625、3本目 ×0.4375、下限 ×0.25 に下がります。
  • フォロー外への配信は ×0.75。フォロワー向けでも、自分の返信とリポストは同じ ×0.75 です。
  • 相互フォローの相手の元投稿への返信は、重みが +15 加算されます。ただし相互の相手のタイムラインの中だけで、見知らぬ人への到達は増えません。

ここまで全部 一次 です。スレッド2本目以降が出ないのは、2本目以降が返信なので同じ条件に当たる、という読みです。推測 だから、1本目で完結する投稿にします。

2-3. ラベル（シャドウバンの実体）

  • 固定ポストの URL 評判。固定した投稿の URL が低評価だと、1週間スパム扱いのラベルが付き、フォロー外のおすすめと通知から落ちます。フォロワーのホームには残ります。lin.ee の判定は不明です。一次
  • 同文判定。日本語を含む CJK 専用の同文ジョブがあります。閾値は非公開で、効果の配線は公開分で未確認です。一次
  • 通知フィルタ。閲覧者が設定していれば、アイコン未設定、電話・メール未確認、作成72時間未満のアカウントの返信は、フォローされていない相手の通知に出ません。一次
  • 返信の LLM 判定。返信先の元投稿の著者が25万フォロワー超だと採点され、0点ならフォロー外の閲覧者の画面から外れます。25万以下は別のスパム判定です。プロンプトは非公開です。一次
  • Under the Hood。自分のアカウントと投稿のラベルを確認できる公式ツールです。試験提供で、自分のアカウントで使えるかは要確認です。一次

Premium の加点は、順位の式に見つかりません。信用スコアの種にはなっていますが、自動スパムルールから外す免除の閾値は、小規模には届かないとみています。一次推測 新規アカウントの順位抑制も、公開コードに見つかりません。むしろ小規模には cold start があります。

言えないのは、本番の学習済みモデル、10%未満の実験、一部のルール、日本語特有の扱いです。

3. 規約の線と、投稿の3段階

決め手は「人が能動的に行うか」です。X の自動化の定義は「人が能動的に行わず、繰り返し動作するもの」で、AI 返信 bot は事前の書面承認が要ります。人が押せば、この論点の大半は当たらないと読めます。推測

3-1. 規約の線

人が投稿、人が返信（下書きは AI）可自動化の定義に当たらないと読める 推測
情報提供目的の自動投稿条件つきラベルと bio での明示、人の管理アカウントとの紐づけが要る
AI 生成の自動返信書面承認が要る事前の書面承認なしは不可

投稿上限は未認証で1日 50投稿・200返信です。一次 法令側は別です。職安法の的確表示は白のみで、広告には職業紹介所である旨を明示します（業務運営要領 p139）。一次 ポジションを初日から宣言する方針が、そのまま当たります。ステマ告示は未到達で、弁護士の確認を推奨します。

3-2. 投稿の3段階

推奨は A です。API の書き込みがなく、$0.20（URL 付き投稿の API 料金）もラベルの論点もありません。B は投稿元のアプリ名が公開されます。C は Automated ラベルと bio での明示が当たるうえ、AI 生成物の承認の論点も残ります。

ただし A には条件があります。純正の予約投稿は、公式ヘルプで確認できていません。使えなければ毎日の手投稿になり、判断軸と衝突するので、段階 B か予約ツールに進みます。B は承認ごとの投稿なので、週1回のまとめ作業に圧縮するには予約ツールの検討が要ります。推測 開始時に画面で確かめます。

4. 運用ノウハウ

証拠の強さ付きです。総じて、一次で固い部分は「何が評価されるか」で、運用の細部は弱い根拠の仮置きが多いです。

4-1. 立ち上げ

  • アイコン設定、電話とメールの確認を初日に済ませます。作成72時間は、フォローされていない人への返信を控えます。一次 CA の返信が本格化するのは、その後と読めます。推測
  • プロフィールは「フォローすると何が得られるか」＋「有料職業紹介事業者（人材紹介）です」。23人から982人になった記録（週次でプロフィールを A/B）が根拠ですが、n=1 です。一次 弱いが安い。
  • テーマは3つに絞ります。読者が揃うほど予測が当たる、という推論です。推測
  • Under the Hood を週1回見ます。
  • LINE の URL はプロフィール欄に置き、固定ポストは無リンクで始めます。短縮や多段転送は挟みません。一次

4-2. 投稿

  • 返信か共有が起きる投稿を作る。問い、比較、同僚に送りたくなる表。重みが根拠です。一次
  • 1本目で完結させる。スレッドの2本目以降はフォロー外に出ません。一次推測
  • 1日1〜3本で始める。仮置きです。増やして有利になる根拠がなく、類似投稿の禁止と著者多様性の減衰があります。
  • 同じ型の連投をしない。規約、CJK の同文ジョブ、ニッチの実測（同じ型30件で反応0）が根拠です。
  • 形式はテキスト＋図から。動画視聴の重みは 0 です。Buffer の集計の値は、テキスト 3.56%、画像 3.40%、動画 2.96%、リンク 2.25% でした（指標の定義は原典で確認）。事業者
  • 時間帯で悩まない。3時間刻みでは差が読めませんでした。一次小標本
  • 煽らない、対象を絞る。ミュートは −58.8、興味なしは −53.07 です。

4-3. 交流

  • 他人への返信は拡散でなく、関係づくりです。フォロー外の For You に出ず、フォロワー向けでも ×0.75 なので、主に届くのはそのスレッドを開く人です。一次
  • 38,100フォロワーで1日100返信を7日続けた記録は、純増350で、主因は自分の投稿でした。一方、開始時23人の記録では、毎日5件以上・約15分の体験つき返信を怠った週に、返信率が 38.5% から 18.9% に落ちています。どちらも n=1 です。一次
  • 相互フォローは相手を選びます。狙うのは同業の SNS 運用者でなく、同世代の当事者、業者でない元当事者、IT 現場の若手です。「相互1000人でも LINE 登録がほぼない」という投稿があります。未検証
  • 25万フォロワー超への薄い返信は分が悪い戦術です。一次推測
  • 返信は人が書きます。CA の日中の返信体制が使えます。X Pro に担当者を追加できるのは Premium 以上です。一次

4-4. 導線

プロフィールクリックの重みは 0 なので、到達の最適化と導線の最適化は別物です。「この人の他の投稿も読みたい」を、投稿の中で作る必要があります。

リンクの減点は、ルールとしては見つかりません。実測は割れています。

  • コードは減点項なし、リンクを開くは +0.2 です。一次 X の製品責任者も減点を否定し、本文に置くよう勧めています（発言のみ）。施工管理の565件では、反応ありの割合がリンク入り 15.2%、なし 11.8% でした（単純比較）。
  • 自己実験では、リンク入りで いいね −24%（p=0.02）、閲覧 −23%（p=0.16）でした。6投稿です。一次 約435万件の観察は、閲覧÷フォロワーの中央値がリンクなし 0.246、ニュースリンク 0.033 でした（2022〜23年）。独立 60アカウントでは、リンクありとなしの比が中央値 1.05 でした（比の定義は原典で確認）。事業者

結論は、どちらに転んでも困らない形にすることです。本文は読み物、リンクはプロフィール。リンクの有無は自分で測ります。減点がなければ、リンクをプロフィールに置くぶん、1段の移動で離脱が増えます。推測

  • LINE は経路別リンクで測ります。note、Threads、TikTok のリンクはありますが、X は未発行です。
  • 特典は「診断、チェックリスト、テンプレ」が空いています（該当15件・8アカウントのみ）。競合は「LINE で求人」「DM で相談」が主です。
  • DM は人が返します。
  • X は1日で消える前提で作ります。凍結の記録は、数秒で戻る例と何か月も戻らない例が同日に併存し、復旧の再現手順は取れませんでした。資産は LINE に移します。

4-5. 計測

  • 週次で見るのは5つ。投稿ごとの表示の中央値、返信率、プロフィールクリック率、リンククリック、X 経由の LINE 登録。最終指標は「運用の分数あたりの応募」です。
  • 平均でなく中央値。ニッチは反応上位10件が総反応の82%を占める裾の重い分布です。無料アカウントの投稿の中央値は100表示未満でした。事業者
  • x_api.py は足場があります。計測だけ先に使ってもかまいません。プロフィール欄のリンクのクリックを API の指標で拾えるかは未確認です。未検証
  • API は読むだけ。非公開指標（リンククリックなど）は投稿後30日以内のみ取れます。月 $1 前後の見込みです。
  • リンク有無の実験。同じ内容を時間差で出すと、類似投稿の禁止に触れうるので、別の内容で交互に出します。n が小さいので方向だけ見ます。推測

5. 実測：受け皿側と読者

5-1. 受け皿側：施工管理（565件）

これは読者そのものでなく、受け皿側（求人・紹介する側）の測定です。

Yahoo!リアルタイム検索からの取得で、全体の標本ではありません。発信者の内訳は、無作為120件を手で分類した値で、±8ポイント程度は構成比の誤差です。元施工管理の個人発信（0/23）は、誘導・商材ありの投稿です。フォロワー数は取れていません。反応数は取得時点の値で、新しい投稿ほど低く出ます。検索語に転職・求人系が多く、求人側が多めに出ている可能性があります。一次小標本

  • いいね中央値は 0。上位10件が総反応の 82% を占めます（切り抜きや恋愛の助言など、求職の文脈から外れた投稿も混じります）。
  • 競合の導線は DM 62件、LINE 35件、プロフィール・固定 11件、無料 12件です。派遣系の1アカウントは、同じ型を1日4回の固定時刻で30件出して反応計 0 でした。ただし応募は反応に出ない形で来ている可能性があり、成果が出ていないとは言えません。
  • 反応を取る型は、年収・転勤・残業の数字つき体験談、断定、職種の裏事情です。
  • 求職者の不信は「未経験なのに施工管理ばかり勧められる」「勝手に応募される」「登録直後から毎日電話」です。疑いの軸は「手数料で動く人か」。競合はここに答えていません。
  • 好意的な型は「ノルマがない」「合わない人には転職しない方がいいと言う」「経験者本人」です。

5-2. 読者側：ユウタ語（1,026件）

語は42語（ユウタの状態に重なる検索語。学歴・職歴の不安、飲食・接客、転職の足踏みなど）、取得は1,026件、686アカウントです。分類は手作業で境界例が多く、検索語の偏りもあります。期間は主に 2026-10-08〜11-07。Yahoo!リアルタイム検索からの取得で、無作為120件を手で分類しました。一次小標本

  • ユウタ型の本人の声は 120件中 10件（8.3%、95%区間でおよそ 5〜15%）。その反応は 0 件です。緩く「自分の状態を一人称で語る当事者」まで広げると 24件（20%）ですが、反応が付いたのは 2件でした。
  • ユウタ層に向けて発信している側は 120件中 40件（33%）で、本人の声の約4倍です。7アカウントだけで取得1,026件の 16% を占めます。
  • 反応の薄さは施工管理と同じです。反応ゼロは 87.0%（893件）、いいね中央値は 0 です。違うのは、誰が居るかです。ユウタ語の界隈は、業者と無関係な雑音（恋愛・就活・学歴論争・成人向け広告）が 36% を占めます。
  • 同じ本文が複数の ID で出る定型連投が 20%。独立した話者は、数字より少ないはずです。
  • 「少ない」は「X に居ない」と同じではありません。ユウタ層は TikTok・Google 検索・LINE など、投稿しない形で動いている可能性が高いです。推測 反応ゼロは、読まれていない証拠でもありません。閲覧数が取れないためです。
空き位置推測
数字つきの体験談は反応を取る型に挙がる一方、受け皿側の元施工管理の個人発信は、反応あり 0/23 でした。空きに見える所と通る所は一致しない可能性があります。
① エージェント不信への正面回答　② 自社の面談由来の、数字つき一次情報（匿名化済み）　③ 同僚に送りたくなるチェックリスト。空いていることと通ることは別で、通るかは測るしかありません。
