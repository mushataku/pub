1. CCNAってどんな資格？

ネットワーク機器の大手 Cisco（シスコ）が出している資格で、ネットワークの基礎を一通りわかっていることの証明になります。インフラの未経験採用では「Linux（LinuC など）」と並んで、いちばん名前が通じる資格です。

Linux とのちがい
Linux＝サーバーの中（OS・コマンド・設定）。CCNA＝サーバー同士をつなぐ道（ケーブル・スイッチ・ルーター・住所のルール）。高橋さんが Linux で立てたサーバーに、ブラウザからたどり着けたのは、この「道」が動いていたからです。

試験は1回で全範囲（2時間・選択問題が中心）。受験料や試験の細かい形式は変わることがあるので、申し込むときに Cisco の公式ページで確かめてください。

2. 出る範囲の地図

試験範囲は6つの分野に分かれています。数字は出題の割合の目安です。上の3つで全体の6割以上。最初はここに時間を使います。

IPの接続（ルーティング）25%
ネットワークの基礎20%
ネットワークアクセス（スイッチ・VLAN・無線）20%
セキュリティの基礎15%
IPサービス（DHCP・DNS・NAT など）10%
自動化とプログラマビリティ10%

Ping-t の章立てもだいたいこの分野ごとです。迷ったら「いまどの分野をやっているか」をこの表で確かめてください。

3. 層で考える（OSI参照モデル）

ネットワークの話は、ほぼ全部「何層の話か」で整理できます。7つの層を丸暗記するより、色のついた3つの層を先に押さえてください。CCNA の大半はこの3つの話です。

7アプリケーション層ブラウザ・メールなど（HTTP・DNS）
6プレゼンテーション層文字コード・暗号化の形
5セッション層通信の始まりと終わり
4トランスポート層TCP と UDP・ポート番号（80＝HTTP、22＝SSH）
3ネットワーク層IPアドレス・ルーターの仕事
2データリンク層MACアドレス・スイッチの仕事
1物理層ケーブル・電気の信号
覚え方のコツ：トラブルの調べ方も下から。「ケーブル刺さってる？（1）→ スイッチまで届いてる？（2）→ IPは合ってる？（3）」。現場でも同じ順番で見ます。

5. IPアドレスと「/24」の読み方

IPアドレスは「何丁目（ネットワーク部）＋何番地（ホスト部）」の2つでできています。/24 は「前から24ビット（＝前の3つの数字）が丁目」という意味です。

192.168.1.10/24

ネットワーク部（丁目）ホスト部（番地）

書き方丁目の長さ番地に使える数つなげる台数
/24前から24ビット8ビット＝256254台
/25前から25ビット7ビット＝128126台
/26前から26ビット6ビット＝6462台
なぜ「2台引く」のか：番地の最初（例 192.168.1.0）は「丁目そのものの名前」、最後（192.168.1.255）は「丁目全員へのお知らせ用（ブロードキャスト）」で、パソコンには使えないからです。
→ 計算式は 2の（32−スラッシュの数）乗 − 2。/26 なら 2⁶−2＝62。

サブネットの計算は CCNA でいちばん点差がつく所です。最初は/24〜/30 の表を手で書けるようにするだけで十分。慣れたら Ping-t のサブネット問題を毎日5問ずつ。

6. Linux とつなげて覚える

高橋さんはもう Linux を触っているので、同じことを自分の仮想サーバーで確かめられます。これが他の未経験の人より強いところです。

 Linux（いつもの仮想サーバー）
$ ip a              # 自分のIPアドレスと /24 などを見る（3層）
$ ip route          # デフォルトゲートウェイ（出口）を見る
$ ping 8.8.8.8      # 相手まで届くか確かめる
$ traceroute 8.8.8.8 # 途中で通るルーターを順に見る
$ ss -tln           # 待ち受け中のポート（4層・nginx なら 80）

CCNA では Cisco の機器を同じように操作します。雰囲気だけ見ておいてください（Ping-t の後半や、無料の練習ソフト Packet Tracer で触れます）。

 Cisco の機器（ルーター）
Router> enable                       # 管理者モードに入る
Router# show ip interface brief       # 各ポートのIPと、つながっているか
Router# show ip route                 # ルーティングテーブル（道の一覧）
Router# configure terminal            # 設定モードへ

Linux の ip a ↔ Cisco の show ip interface brief、ip route ↔ show ip route。対にして覚えると早いです。

8. 面接での言い方

面接で強いのは「研修で頑張ります」より、いま自分で進めていることを具体で言えることです。空欄を自分の数字で埋めておいてください。

こう言える形

「Linux で仮想サーバーを立てて Web ページを表示するところまで自分でやりました。いまはその次として、Ping-t で CCNA をの章まで進めています。月の受験を目標に、毎日分続けています。」

避けたい形

「CCNA の勉強をしています。」→ 何を・どこまで・いつまでが無いと、面接官は進み具合を想像できません。

「なぜ CCNA？」と聞かれたら：「サーバーを立ててみて、そこに届くまでの道（ネットワーク）がわかっていないと、止まったときに原因を探せないと感じたからです」。高橋さん自身の体験から出る理由なので、そのまま使えます。

9. 確認クイズ（押すと答えが開きます）

Q1. MACアドレスを見て相手を探すのは、スイッチ？ルーター？

スイッチ（2層）。ルーターは IPアドレスを見ます（3層）。

Q2. 192.168.1.10/24 のネットワーク部（丁目）はどこまで？

192.168.1 まで。最後の 10 が番地（ホスト部）です。

Q3. /26 のネットワークには、パソコンを何台つなげる？

62台。2⁶＝64 から、丁目の名前と全員へのお知らせ用の2つを引きます。

Q4. 違うネットワークの相手に送るとき、パソコンはまずどこに渡す？

デフォルトゲートウェイ（部屋の出口のルーター）。Linux では ip route の default の行で見られます。

Q5. nginx が待ち受けている 80 番は何層の話？

4層（トランスポート層）のポート番号です。SSH は 22 番。

Q6. 通信がつながらないとき、どの順番で確かめる？

下の層から：ケーブル（1）→ スイッチまで（2）→ IP・ゲートウェイ（3）→ ポート（4）。
