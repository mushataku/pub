IPアドレス＝ネットワークの中の住所。住所を打つと、その住所の機械のWebサーバーに届きます。

通り道：どこのブラウザで、どの住所を開く？

ここは面接でよく突っ込まれます。VirtualBox の最初の設定（NAT）のままだと、PC側のブラウザから仮想マシンの住所には直接届きません。届く道は A〜C の3本です。高橋さんはどれだったか思い出してみてください。

localhost＝「この機械じしん」を指す名前（中身は 127.0.0.1）。どの機械で打つかで、指す先が変わります。

💻 自宅のPC
🌐 PCのブラウザ
B─→localhost:8080─→ 📦 届く
C─→192.168.…─→ 📦 届く
✕─╳10.0.2.15届かない
📦 仮想マシン
A🌐 中のブラウザ ─→ localhost ─→ 📄 nginx
A 仮想マシンの中のブラウザ
Ubuntu の画面の中で Firefox などを開く。いちばん簡単（画面のある Ubuntu Desktop のときだけ）
B ポートフォワード
VirtualBox の設定で「PCの8080番 → 仮想マシンの80番」に転送する
C ブリッジ接続
仮想マシンが家のネットワークに1台として並ぶ。住所は ip a で調べる
✕ VirtualBox の NAT のまま
ip a で見える 10.0.2.15 を打っても届かない。ここで詰まる人が多い（VMware の NAT なら届く）

3. サーバーを立てる手順（Ubuntu と nginx の例）

画面に近い形で並べました。$ の後ろが自分で打つ部分です。「何のために打つか」を言えるようにしておきましょう。

  1. ソフトの一覧を最新にする
    $ sudo apt update
    sudo＝管理者の権限で　／　apt＝Ubuntu でソフトを入れる道具
  2. Webサーバー（nginx）を入れる
    $ sudo apt install nginx
    Ubuntu では、入れた時点で自動で起動します
  3. 動いているか確かめる
    $ systemctl status nginx
● nginx.service - A high performance web server
     Active: active (running)
    緑で active (running) なら動いている。画面が止まったら q で抜ける。止まっていたら sudo systemctl start nginx
  4. まず仮想マシンの中から見えるか確かめる
    $ curl localhost
<title>Welcome to nginx!</title> ...
    ページの中身（HTML）が返れば、Webサーバーは動いている。command not found と出たら sudo apt install curl
  5. ブラウザで開く（住所は 2. の通り道 A〜C のどれか）
    localhost ／ localhost:8080 ／ 192.168.…
    Welcome to nginx!
    If you see this page, the nginx web server is successfully installed...
    この画面が出たら成功
Apache を使った場合の読み替え nginx→apache2 Welcome to nginx!→Apache2 Ubuntu Default Page 例：systemctl status apache2

見えないときは、この順で原因を絞る

高橋さんが面白いと話していた「ちゃんと動いているかを確かめる」は、まさにこの作業です。

Q1. systemctl status nginx は active？
はい → Q2 へ
いいえ → 止まっている。sudo systemctl start nginx
Q2. curl localhost でページが返る？
はい → Q3 へ
いいえ → command not found なら curl を入れる。それ以外は ss -tlnp で80番が開いているか見る
Q3. ブラウザから見える？
はい → 成功
いいえ → 通り道を疑う（2. の A〜C。VirtualBox の NAT のままなら届かない）

7. 確認クイズ（押すと答えが開きます）

Q1. Linux と Ubuntu の関係は？

Linux はエンジン（OSの中心）、Ubuntu はそれを積んだ車種（配布版）の1つ。

Q2. 仮想マシンを使う良いところは？

PCを買い足さずに練習台が手に入り、間違えても作り直せる。元のPCには影響しない。

Q3. Webサーバーが動いているか確かめるコマンドは？

systemctl status nginx。active (running) と出れば動いている。抜けるときは q。WSL なら sudo service nginx status。

Q4. 中からは見えるのに、PCのブラウザから見えない。何を疑う？

通り道。VirtualBox の NAT のままなら届かないので、ポートフォワード（localhost:8080）かブリッジ接続にする。

Q5. localhost とは？

「この機械じしん」を指す名前（127.0.0.1）。仮想マシンの中で打てば仮想マシン、PCで打てばPCを指す。

Q6. 自分がよく使うコマンドを確かめるには？

history。文字で探すなら Ctrl＋R。

分からないところがあれば、LINE でいつでも聞いてください。次の練習で、6. の下線を一緒に埋めましょう。
