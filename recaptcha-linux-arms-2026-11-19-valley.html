クラウドの箱（Cloud Run Job）から家の回線を出口にして、fresh2 の鍵の的ミラーを3腕で各16回（8回×2本・交互・先に決めた数で止めた）撃った。2本目は出口の経路（SOCKS）が落ち続け、24回中21回が error になった。1本目も最後の約3分（15:39〜15:41）で同じ error が出た。error は票の決まりどおり失敗に数えた。この回の腕の差は、名乗りの効果より経路の断の偏りを強く映す。

  • 即時通過（error も失敗に数える・Wilson 95%）: headed 4/16（0.10〜0.50）・headed+linux 6/16（0.19〜0.61）・headed+linux+aged 0/16（0.00〜0.19）。
  • headed との差（Newcombe 95%）: +linux +12.5 点（−18.5〜+40.6）＝0 をまたぐ。+aged −25.0 点（−49.5〜−0.6）＝0 をまたがない。ただし +aged は error が 11/16 で、3腕の中で一番多い。

  • Job bot-lab-recaptcha-cloud（image git-ca1082590a＝窓の管理役・音・コア数を入れた版）・鍵 fresh2・出口＝PC の Tailscale 出口ノード（AS2514・IP の sha8 b8acdf02）。2本とも出口の門は ok（撃ち始めの時点）。
